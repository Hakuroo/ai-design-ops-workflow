## Filled Example

**Task title**  
Create landing page hero section for industrial construction campaign

**Context**  
A fictional industrial construction client needs a landing page hero section to introduce a campaign focused on reliability, planning, and large-scale project delivery. The section will be used as a web-ready example for review.

**Objective**  
Create a clean, responsive hero section that communicates trust, scale, and practical construction expertise.

**Deliverables**

- Semantic HTML file for the hero section.
- CSS file with responsive styling.
- Final copy for headline, body text, CTA, and feature list.
- Short QA notes before delivery.

**Assets required**

- Approved campaign message.
- Brand color direction or neutral placeholder palette.
- Final CTA destination if this becomes a live page.
- Optional construction image or visual direction if a full layout is expanded later.

**Technical requirements**

- Use clean HTML and CSS.
- No external dependencies.
- Must work on desktop and mobile.
- CTA should be clear and easy to find.
- Code should be readable for handoff.

**AI support needed**

- Summarize rough brief into clear requirements.
- Generate copy options for review.
- Suggest acceptance criteria.
- Review HTML/CSS for simple improvements.

**Acceptance criteria**

- [ ] Hero includes a clear title, short paragraph, CTA, and feature list.
- [ ] Section is responsive and readable on small screens.
- [ ] HTML uses semantic structure.
- [ ] CSS is organized and does not rely on external libraries.
- [ ] Copy is human-reviewed and does not include unsupported claims.
- [ ] Final files are documented in delivery notes.

**QA checklist**

- [ ] Desktop layout reviewed.
- [ ] Mobile layout reviewed.
- [ ] CTA text reviewed.
- [ ] Feature list spacing reviewed.
- [ ] Color contrast checked at a basic level.
- [ ] AI-assisted copy reviewed and edited by a human.

**Status**  
Review

**Owner**  
Junior Creative Technologist / Design Ops support

**Deadline**  
Example deadline: end of current production sprint
