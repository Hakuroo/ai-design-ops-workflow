# Prompt Examples

These prompts show practical ways to use AI tools during a Design Ops and digital production workflow. They are starting points and should always be reviewed by a human.

## Understanding a Creative Brief

```text
You are helping me organize a creative production brief for a landing page campaign.

Please read the brief below and return:
1. A plain-English summary.
2. The target audience.
3. The main message.
4. Required deliverables.
5. Missing information or questions to ask.
6. Possible production risks.

Keep the language professional and concise. Do not invent client details.

Brief:
[Paste brief here]
```

## Generating Copy Variants

```text
Act as a copy support partner for a digital campaign.

Create 5 hero headline options, 5 short subhead options, and 5 CTA label options for the campaign below.

Tone:
- Professional
- Direct
- Confident
- Not too sales-heavy

Audience:
[Audience]

Campaign goal:
[Goal]

Important message:
[Message]

Avoid making claims that are not supported by the brief.
```

## Creating Visual Exploration Prompts

```text
Help me create visual exploration prompts for an industrial construction campaign.

The visuals should feel:
- Reliable
- Modern
- Precise
- Built for large-scale work

Generate 6 image-generation prompts for early mood exploration. Include notes for composition, lighting, material texture, and color direction.

Do not include real company names, logos, or confidential project references.
```

## Asking Claude or ChatGPT to Review Code

```text
Please review this HTML and CSS for a responsive landing page hero section.

Focus on:
1. Semantic HTML.
2. Responsive layout issues.
3. Accessibility basics.
4. CSS clarity.
5. Any simple improvements that would help handoff.

Do not rewrite everything. Suggest only practical changes.

Code:
[Paste code here]
```

## Asking Cursor to Help Debug a Layout

```text
The hero section works on desktop, but on mobile the CTA and feature list feel cramped.

Please inspect the HTML and CSS in these files:
- examples/landing-section.html
- examples/landing-section.css

Help me adjust spacing, stacking, and button width for screens under 700px. Keep the design simple and avoid adding JavaScript.
```

## Generating a QA Checklist

```text
Create a QA checklist for a responsive landing page hero section.

Include checks for:
- Layout
- Mobile responsiveness
- Copy accuracy
- CTA behavior
- Accessibility basics
- SEO basics
- Asset quality
- AI-generated content review

Format it as a practical checklist for a junior production team member.
```

## Creating Ticket Acceptance Criteria

```text
Turn this production task into clear acceptance criteria.

Task:
[Paste task description]

Return:
1. Functional acceptance criteria.
2. Design acceptance criteria.
3. Content acceptance criteria.
4. QA acceptance criteria.

Use clear checklist language. Keep it realistic for a small digital production task.
```
