# AI Design Ops Workflow

A practical workflow showing how AI tools, web development, and design operations can support creative teams in digital production.

This portfolio demo shows how a creative request can become organized tasks, AI-assisted research, copy support, web-ready implementation, quality review, and clean delivery documentation. It is designed around a junior Creative Technologist / Design Ops workflow in a creative agency context.

The project is intentionally focused and practical. It emphasizes digital production habits, not complex engineering or fake confidential client data.

## Why This Project Exists

Creative teams often move quickly across briefs, visual ideas, landing pages, campaign assets, feedback, and delivery deadlines. AI tools can help with structure and speed, but the work still needs human review, clear task ownership, and quality control.

This project demonstrates how AI-assisted tools can support a structured workflow by helping with:

- Turning a messy brief into clear requirements.
- Creating production tickets with acceptance criteria.
- Drafting copy options for human editing.
- Supporting visual exploration prompts.
- Reviewing code and layout decisions.
- Documenting QA before delivery.

## Workflow Overview

1. Receive the creative brief.
2. Clarify missing requirements and constraints.
3. Convert the brief into small production tickets.
4. Use AI for research, structure, copy support, and review.
5. Explore visual directions with design and image-generation tools.
6. Implement web-ready sections with clean HTML and CSS.
7. Review layout, copy, accessibility basics, assets, and links.
8. Deliver final files with notes and next steps.

## Tools Used

This workflow can include:

- ChatGPT for brief analysis, task structure, copy support, and QA planning.
- Claude for document review, code review, and alternate copy directions.
- Cursor for AI-assisted coding and debugging.
- Figma for layout, design systems, handoff, and visual review.
- Midjourney, ComfyUI, and Krea.ai for visual exploration and image direction.
- HTML, CSS, and JavaScript for web implementation.
- Notion/Jira-style workflows for ticketing, status tracking, and delivery notes.

The focus is not to automate the creative process fully. The focus is to use AI-assisted tools inside a practical workflow with human review.

## What This Project Demonstrates

- Shows how a creative brief can become clear production tasks.
- Demonstrates how AI tools can support research, copy, organization, and review.
- Shows basic front-end implementation using semantic HTML, CSS, and JavaScript.
- Demonstrates structured QA habits before final delivery.
- Highlights why human judgment and QA remain important in AI-assisted production.
- Shows how documentation and Notion/Jira-style workflows can keep creative, design, and development work aligned.
